# RecBole 性能指标中文说明设计

## 目标

让推荐控制台中的 RecBole 性能指标更容易理解，同时保持指标键名和后端 API 契约不变。

## 展示方案

性能指标下拉框显示中文名称，并在括号中保留通用指标名：

| 指标值 | 显示名称 | 当前指标说明 |
| --- | --- | --- |
| `Recall@20` | `召回率（Recall@20）` | 衡量前 20 条推荐覆盖用户感兴趣内容的程度，越高越好。 |
| `NDCG@20` | `排序质量（NDCG@20）` | 衡量前 20 条推荐的相关性和排序位置，相关内容越靠前得分越高。 |
| `Hit@20` | `命中率（Hit@20）` | 衡量前 20 条推荐中至少命中一条用户感兴趣内容的比例，越高越好。 |
| `Precision@20` | `准确率（Precision@20）` | 衡量前 20 条推荐中用户感兴趣内容所占的比例，越高越好。 |

下拉框下方显示当前选中指标的说明。用户切换指标时，说明同步更新。

## 数据与兼容性

- `option.value`、组件内部 `metric` 和 API 请求参数继续使用标准键名，不做中文化。
- 前端根据指标值覆盖后端返回的英文标签，避免依赖后端展示文案。
- 后端未来返回未知指标时，显示后端标签或指标值，不阻断选择和查询。
- 不修改后端接口、数据库字段或训练指标文件。

## 测试与验证

- 组件测试验证四个标准指标具有中文名称和说明。
- 组件测试验证默认值及请求使用的指标值仍为 `NDCG@20`。
- 运行 `hls-web` 测试和构建。
- 启动本地前端，用桌面和移动尺寸检查下拉框、说明文字及切换行为，确保文字不溢出或遮挡。
